# Task: Semantic Capability P — Small-Book Fixture, Alexandria Parity, and Public E2E

## Problem Statement
The repository fixtures contain single-chapter text and one-spine-item EPUB examples, but no realistic small book that exercises the requested semantic capability chain. There is also no parity oracle for the caller-specified Alexandria walks 2a scene segmentation, 2b character discovery, 2c alias resolution, 2d scene presence, 2e span attribution, and 2f character description. This plan adds a generic, repository-owned oracle and a production/public acceptance path that compares deterministic and optional-provider modes without copying SQLite, audiobook, or consumer-specific state.

**Prerequisite:** Plans L, M, N, and O. The fixture must exercise their actual production StageWork registry, ledger, replay projections, and public query/search routes rather than test-only direct writes.

**Scope:** `tests/fixtures.py`, a new focused semantic fixture/oracle test module under `tests/`, `tests/test_production_stage_registry.py`, `tests/test_production_runner.py`, `tests/test_api_contract.py`, projection/query/search tests, and the final parity report under `artifacts/reports/`. Documentation may be updated only to describe verified behavior. Do not add a second semantic pipeline, copy Alexandria's storage/schema, or turn the fixture into a provider-specific golden database.
