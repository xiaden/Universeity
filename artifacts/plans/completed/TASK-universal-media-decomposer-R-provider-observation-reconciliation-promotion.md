# Task: Semantic Capability R — Provider Observation Reconciliation Promotion

## Problem Statement
Plans L–Q established the generic typed semantic contract, honest optional-provider gates, multi-entity resolution, rich ledger reconciliation, replay-built active edges, bounded query/search/question reads, and the Lantern Keeper parity/public-E2E fixture. They also deliberately left one mandatory functional gap: `src/umd/jobs/production.py::_reconciliation_input` reconstructs only a deterministic analysis (`SemanticTextAnalyzer(None, provider=None, model=None)`) and labels the reconciliation input deterministic, even though `_structural_analysis` has already run the configured provider-aware analyzer and durably stored validated provider observations as evidence. Provider aliases, traits, scene/presence, utterance/speaker, and supported relationship candidates therefore stop at evidence and never reach the existing reconciliation command path, scalar current reads, replay-built active edges, or edge-derived search/question results.

This follow-up wires the already-validated, committed provider observations into the existing deterministic-plus-provider reconciliation input without re-invoking a provider or adding an authority. It must preserve exact segment/evidence support, generated-by/provider/model/model-version/prompt/config provenance, confidence and semantic state, deterministic baseline observations, honest malformed/unsupported/gated degradation, ambiguity behavior, idempotency, and user authority. Provider/model output remains an observation only; `SemanticCommandService.assert_semantic` and the append-only ledger remain the sole assertion path, `current_state` remains reducer-owned, active edges remain replay-only, and search remains active-edge-derived.

**Prerequisite:** `TASK-universal-media-decomposer-Q-semantic-capability-verification.md` and the completed L–P implementation plans. Q is historical verification evidence: its documented provider-promotion limitation and live/Docker/Hatchet gates must not be rewritten as if Q had implemented or verified this follow-up.

**Scope:** `src/umd/jobs/production.py` reconciliation-input and resolution compatibility, narrowly necessary typed observation rehydration/validation, existing reconciliation/event tests, PostgreSQL/StageWork fixture tests, and public structured/semantic/evidence/search assertions. Update contracts/README and a follow-up report or affected provider/query docs only to describe the verified behavior. Do not create a DD.
