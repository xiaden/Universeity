# Task: Universal Media Decomposer — Durable Jobs, Text, and Image Pipelines

## Problem Statement

Build the first real decomposition stages on top of Plan A: one in-repository lineage definition executed only by Hatchet, durable stage records with database-authoritative idempotency, selective descendant invalidation, and representative text/book/raster/sequential-art pipelines. Stages must emit common provenance-bearing envelopes and preserve independent branches; a failed late stage must not re-ingest or re-derive successful early work.

**Prerequisite:** `TASK-universal-media-decomposer-A-foundation-authority.md`. Use the binding contracts in `artifacts/designs/parts/universal-media-decomposer/CONTRACTS.md`.

## Completion Criteria

- Hatchet is the only v1 scheduler; database uniqueness and handler checks provide effective-once stage completion independent of engine idempotency.
- A late-stage retry resumes from committed artifacts and leaves successful segment/evidence IDs/checksums unchanged; invalidation selects descendants only.
- Text/book and image/sequential-art fixtures produce the bounded DD baseline, preserve raw bytes and provenance, quarantine unsupported/malformed items, and expose capabilities accurately.
- Focused DAG, job, text, image, sandbox-boundary, static/type/lint, and integration tests pass; no direct projection writer is introduced.
