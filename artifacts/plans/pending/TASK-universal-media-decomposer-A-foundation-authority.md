# Task: Universal Media Decomposer — Foundation and Semantic Authority

## Problem Statement

Implement the greenfield foundation for the approved Universal Media Decomposer architecture. The service must preserve the non-negotiable separation `OCFL source bytes -> PostgreSQL evidence/segments -> append-only semantic ledger -> disposable projections`, before modality workers or query surfaces are added. This plan is the prerequisite for every later plan and must establish stable IDs, versioned locators, provenance, event schemas/upcasters, Tier-0 state, audit, and source ingestion without inventing a downstream-consumer ontology.

Authoritative requirements: `/workspace/Universeity/Task.md` lines 1–1739. Design: `/workspace/Universeity/artifacts/designs/pending/DD-universal-media-decomposer.md`. Supporting research and approval: the six process artifacts listed in `artifacts/designs/parts/universal-media-decomposer/README.md`. `DD_REQUIRED` is immutable, T1–T8 are complete, and PatternEnforcer approved the DD for handoff.

**Prerequisite:** None. Shared contracts: `artifacts/designs/parts/universal-media-decomposer/CONTRACTS.md`.
