# Task: Universal Media Decomposer — Production Stage Composition and API Ingestion

## Problem Statement
Replace the historical API test facade with a real production execution path. `build_context()` currently installs `InMemoryJobStore` and `SynchronousRunner`; source ingestion submits an empty registry and can swallow submission failures. The repository already has the authoritative DAG, `DurableStageExecutor`, Postgres stage/job repositories, OCFL storage, and real modality implementations, but no production registry composes them. This plan makes API ingestion dispatch the complete ordered pipeline and persist real segments, evidence, semantic results, and projections only after durable stage output commits.

This is remediation after historical Plans A–F, not a redesign. Hatchet remains the sole v1 scheduler; this plan may use `DurableDAGRunner` as the executor-facing seam and test driver, but must not introduce a competing production scheduler or restore fake completion. `SynchronousRunner` remains available only as an explicitly test-only double. Binary/stream ingestion must preserve immutable bytes and the existing versioned REST, provenance, evidence/semantic separation, append-only ledger, and consistency contracts.

**Prerequisite:** Historical Plans A–F. This plan supplies the runtime composition required by Plan I's Hatchet worker and Plan J's public-boundary release validation.
