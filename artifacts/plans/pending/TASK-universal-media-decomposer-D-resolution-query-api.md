# Task: Universal Media Decomposer — Resolution, Alignment, Projections, Query, and API

## Problem Statement

Turn independently decomposed evidence into reversible cross-source semantics and usable API surfaces. Preserve languages, editions, continuities, adaptations, contradictions, omissions, additions, and alternative realizations instead of collapsing them. Build only the approved v1 projection set (`current_state`, exact/full-text, pgvector) and bounded relational graph-like querying; keep Neo4j/RDF/XTDB/dedicated-vector systems as replay-only future extensions.

**Prerequisite:** `TASK-universal-media-decomposer-C-av-subtitles-providers.md`. Use `artifacts/designs/parts/universal-media-decomposer/CONTRACTS.md`.
