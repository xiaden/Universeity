# Task: Universal Media Decomposer — Public API E2E, Hosted Docker CI, and Release Gate

## Problem Statement
Replace the historical internal-service acceptance claims with genuine API-boundary proof and add the missing hosted Docker workflow. Existing tests exercise internal modality/services and explicitly rebuild projections; no `.github/workflows` directory exists, and local Docker tests skip honestly. This plan validates the complete production API/worker/Hatchet path from several heterogeneous real-format sources through persisted evidence, alignment, resolution, semantic query, correction, selective invalidation/rerun, restart recovery, and audit. It also makes GitHub Actions execute every Docker-dependent Definition-of-Done check on a hosted runner without DinD or socket mounting.

This is the final remediation plan after G–I. It may update documentation only after behavior and CI are green. It must preserve all A–F contracts and disclose permitted gates explicitly. A gated optional feature is acceptable only when its status and gate reason are observable and the CI matrix proves the required baseline; no unresolved FAIL may be hidden as a skip. The final QA/adversarial review is a release blocker and must repair findings before the measured suite and release matrix are published.

**Prerequisite:** `TASK-universal-media-decomposer-I-hatchet-worker-integration.md` and `TASK-universal-media-decomposer-H-local-providers-modalities.md`.

- Final adversarial QA repairs all findings; the DoD matrix has no unresolved mandatory FAIL and every GATED status is explicitly permitted, observable, and proven by the appropriate CI or runtime command.
- Release changes are committed with reproducible commands and evidence for the final architecture and validation results.
