# Task: Universal Media Decomposer — Full Validation and Release Gate

## Problem Statement

Prove the complete implementation against the authoritative requirements and repair any findings before release. This is not a superficial smoke-test phase: it must generate deterministic heterogeneous fixtures, exercise every v1 modality and operational failure mode, verify replay and storage ownership, and run the mandatory correction → invalidation → selective-rerun path across Tier-0 and Tier-1. The final adversarial review must specifically probe provenance loss, source/semantic conflation, irreversible resolution, stale semantics, locator drift, language/adaptation collapse, races, restart behavior, cross-store inconsistency, and unsafe media handling.

**Prerequisite:** `TASK-universal-media-decomposer-E-operations-docs-deployment.md`. Use `artifacts/designs/parts/universal-media-decomposer/CONTRACTS.md`.
