# Task: Universal Media Decomposer — Operational Hatchet Scheduler and Worker

## Problem Statement
Turn the Hatchet seam from a pure specification into the one operational v1 scheduler. `HatchetRunner` currently raises when no client exists, submits a placeholder workflow when a client is injected, and returns no real events; `deploy/cli.py worker()` registers no stage run functions. The completed stage executor and Plan G registry provide the actual work, but the worker must bind each Hatchet task to `DurableStageExecutor`, persist job/stage/audit state, and resume safely after process/container restart.

Hatchet is mandatory as the sole scheduler for v1. Do not add a hand-rolled production queue, second DAG engine, Dagster, Temporal, or a competing process loop. The exact SDK/server release must be pinned only after live retry/cancel/restart shape tests pass against the same Compose/CI stack. If the local environment lacks the SDK or server, local capability is `configured-but-unavailable`/`gated`; that is not release evidence. Plan J must execute the live Docker validation and fail the release gate if the pinned scheduler does not perform real work.

**Prerequisite:** `TASK-universal-media-decomposer-G-production-runner-api.md`; Plan H may be completed before or alongside this plan, but provider stage work must use the same worker binding.
