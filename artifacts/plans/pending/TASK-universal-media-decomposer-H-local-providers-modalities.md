# Task: Universal Media Decomposer — Real Local Providers and Modality Composition

## Problem Statement
Activate useful local-provider behavior behind the existing swappable, sandboxed contracts. The reference modality code is real and tested, but `FasterWhisperAsrProvider` always reports “runtime not wired,” `AudioPipeline` bypasses configured provider dispatch, and the deployment/runtime does not validate an ordinary-speech ASR path. Raster OCR must remain useful with the Tesseract baseline when available, and video must compose actual audio extraction plus ASR, independent subtitles, and visual/temporal evidence rather than merely announcing those branches.

This plan depends on Plan G's production stage registry and preserves all A–F contracts: raw bytes remain immutable, evidence never silently becomes semantic truth, confidence is scoped, model/tool/config provenance is retained, and optional capabilities report `active`, `reference-only`, `configured-but-unavailable`, `gated`, or `disabled`. Pyannote licensing/weights, PaddleOCR, hardened sandbox profiles, enhanced PyAV/PySceneDetect, and other explicitly permitted gates must remain honest; a missing optional provider may not fabricate identities or silently claim active behavior.

**Prerequisite:** `TASK-universal-media-decomposer-G-production-runner-api.md`.
